# Preparing real data

Use cloud-masked Landsat Collection 2 surface reflectance for red/NIR, a documented thermal/LST workflow, and a land-cover raster aligned to the same projected grid. Record acquisition date, cloud mask, thermal coefficients, emissivity method, CRS, resolution and classification validation before converting arrays to the `.npz` schema in the README.

Validate LST against an appropriate reference where possible. Daytime satellite LST does not replace near-surface air-temperature monitoring or social-vulnerability evidence.
